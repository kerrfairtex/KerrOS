# Optional dependencies

## IPC actor-mesh (C-16 / ADR-012)

Install only when you want the native nng backend:

```bash
pip install pynng
```

Without pynng, KerrOS still provides `backend: socket` (stdlib TCP).
Config `actor_mesh.backend: nng` soft-falls back to socket if pynng is missing.

pynng>=0.8.0

## S3 Object Lock mirror (ADR-022)

Install only when `audit_object_lock.backend: s3_object_lock` is enabled:

```bash
pip install boto3
```

Without boto3, the default `local_mirror` backend still works; `s3_object_lock`
soft-fails (or fails the seal when `strict: true`).

# boto3>=1.28.0

## NATS actor-mesh backend (ADR-023)

Install only when `actor_mesh.backend: nats` is enabled:

```bash
pip install nats-py
```

Without nats-py, KerrOS soft-falls back to `socket` (same pattern as pynng).
JetStream soft client (ADR-028) also uses nats-py when
`actor_mesh.nats.jetstream.enabled` is set; tests inject an in-memory client.

# nats-py>=2.6.0

## Actor mesh TLS

Stdlib ``ssl`` only — no extra package. PEM paths via `actor_mesh.tls` /
`KERROS_ACTOR_MESH_TLS_*`.

## Offline RAG embeddings + FAISS (ADR-051)

```bash
pip install sentence-transformers   # nomic / MiniLM / bge
pip install faiss-cpu               # optional; numpy Fake index works without it
# numpy is usually already present via sentence-transformers
```

Without sentence-transformers, KerrOS uses deterministic hash mock embeddings.
Without faiss-cpu, FAISS soft store uses a numpy cosine index under
`data/faiss/kerros_memory.npz`. SQLite FTS remains primary either way.

## Offline coding index (ADR-052)

```bash
# ripgrep is typically an OS package: apt/brew install ripgrep
pip install tree-sitter   # optional; Fake regex symbols work without it
```

Claw tools: `code_index_build`, `code_symbols`, `code_search`
(`/code-index`, `/symbols`, `/code-search`). Index under `data/code_index/`.

## Unsloth LoRA → GGUF (ADR-053 / Phase D)

```bash
# Optional GPU host only — never required for CI:
pip install unsloth   # + CUDA torch stack (operator-owned)
# llama-quantize from a local llama.cpp build
./scripts/export_qwen05_lora_gguf.sh plan
```

Fake plan works without Unsloth. `provisioned_production` stays False.
